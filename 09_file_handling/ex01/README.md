# Exercise 1: Create and Write to a File
 
## Description
Write a C program that creates a new file named `data.txt` and writes two lines of personal information (name and age) into it using `open()` and `write()`. Then display a success message on the console using `write()`.
 
## Assignment File
- `solution.c`
## Expected Files
- `solution.c`
- `data.txt`
## Allowed Functions
- `open`, `write`, `close`
## Examples
### Expected Output (console)
```text
Data successfully written to data.txt.
```
 
### Content of `data.txt`
```text
Name: Alice Johnson
Age: 30 years
```
