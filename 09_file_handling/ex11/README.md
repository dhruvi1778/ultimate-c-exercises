# Exercise 11: Uppercase Conversion
 
## Description
Read the content of `data.txt` (from Exercise 3) and write it to a new file `output_upper.txt`, converting all lowercase letters to uppercase. Numbers, symbols, spaces and newlines must stay unchanged. You must do the conversion yourself (no `toupper`).
 
## Assignment File
- `solution.c`
## Expected Files
- `solution.c`
- `data.txt`
- `output_upper.txt`
## Allowed Functions
- `open`, `read`, `write`, `close`
## Examples
### Content of `output_upper.txt`
```text
NAME: ALICE JOHNSON
AGE: 30 YEARS
DATE APPENDED: 2025-10-15
STATUS: SUCCESSFULLY APPENDED.
```
